Detailed Functionality

Two Powerful Notification Types

1. Pop-Up (Toast) Style

  • Appears as a non-intrusive popup on the screen.
  • Users can dismiss the notification after reading.
  • Supports rich text messages for clear communication.
  • Ideal for: Maintenance alerts, meeting reminders, or task updates.

2. Breaking News (Marquee)

  • Scrolling text banner at the top of the Odoo interface.
  • Customizable Styling: Set custom background color (e.g., Red for critical) and font color.
  • Movement Control: Toggle text movement and set direction (Left-to-Right or Right-to-Left).
  • Font Size: Adjust text size for better visibility.
  • Expiry Date: Set a date/time for the banner to automatically disappear.

Management & Tracking

State Workflow

Manage the lifecycle of your notifications:

  • Draft: Prepare your message without sending it.
  • In Progress: Notification is active and visible to users.
  • Finish/Cancelled: Stop displaying the notification.
Read Receipts

Track engagement with your announcements:

  • See exactly which users have marked the notification as "Read".
  • Filter active notifications to exclude those who have already acknowledged them.
  • Ensure critical information is received by your team.

Configuration

Enable User Permissions

To allow a user to create and send notifications, you must grant them the Manager role:

  1. Navigate to Settings → Users & Companies → Users.
  2. Open the user's profile.
  3. Under the Other tab, find the Web Notifications field (in the Other section).
  4. Set the value to Web Notification Manager.

Access the App

Once permissions are granted, simply refresh your browser page. The Web Notification app will appear in your main menu.

Clicking this menu allows you to create new notifications, manage templates, and review history.

Creating a Notification

Simple & Intuitive Interface

The notification form is designed for speed and ease of use:

  • Name: Internal reference for the notification.
  • Type: Choose between 'Pop-Up' or 'Breaking News'.
  • Users: Target 'All' users or select specific individuals.
  • Message: The content displayed to users.

Once ready, click SUBMIT to broadcast the message immediately!

Configuring Breaking News

Customize the appearance and behavior of your scrolling banner in the Breaking News Notifications tab:

  • Colors: Set custom Background and Font colors to match your urgency or branding.
  • Font Size: Adjust text size (in pixels) for better readability.
  • Animation: Enable 'Moving Text' and choose the direction (Left-to-Right or Right-to-Left).
  • Expiry: Set an expiration date to automatically remove the banner.

Templates

Save time by creating Notification Templates for recurring messages (e.g., "Weekly Maintenance", "Server Restart in 10 mins"). Load templates with a single click in the notification form.

Notification History

Review Past Alerts

Users can easily access their notification history to catch up on missed messages:

  • History Tab: Switch to the 'History' tab in the notification center.
  • Status: Quickly see which notifications are New or already Read.
  • Date & Time: timestamps ensure you know exactly when an alert was sent.
